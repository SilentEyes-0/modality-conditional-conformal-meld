# Modality-Conditional Conformal Prediction for Multimodal Emotion and Sentiment Recognition on MELD

This repository contains the code, configurations and tests for a study of split conformal prediction under missing and corrupted modalities. One conformal threshold is calibrated for each text–audio–video availability pattern (Mondrian calibration on the availability mask) and compared with two global thresholds, on emotion (7 classes) and sentiment (3 classes) recognition.

The pipeline uses frozen text, audio and video features, a concatenation classifier trained with modality dropout, simulated missing and corrupted modalities, dialogue-grouped splits, five seeds (42 to 46) and a frozen analysis plan. Mask-conditional calibration is not new; the contribution is empirical evidence on a conversational benchmark.

**Authors:** Anjan Manna, Aman Kumar, Ayush Kumar Singh, Anurag Karmakar, Anubhaba Swain.
School of Computer Engineering, Kalinga Institute of Industrial Technology (KIIT), Bhubaneswar, India.

## Dataset

The study uses **MELD** (Multimodal EmotionLines Dataset; Poria et al., ACL 2019), built from dialogues of the television series *Friends*. It has 13,708 utterances with seven emotion labels (anger, disgust, fear, joy, neutral, sadness, surprise) and three sentiment labels. The released files used here contain 1,038 train, 114 dev and 280 test dialogues.

MELD is not included in this repository. Obtain it from the original authors (https://affective-meld.github.io/) and follow its licence and terms of use. All three modalities are present for every utterance, so all missingness in this study is simulated.

## Requirements

- Python 3.12
- ffmpeg on the system path (audio extraction)
- No GPU is needed; the study ran on CPU. Video feature extraction is the slowest step.

Download MELD from the original source (https://affective-meld.github.io/) and place it as follows. The folder paths are set in `configs/experiment.yaml`.

## Reproducing the experiments

The commands below are for Windows PowerShell with the virtual environment active. `scripts/run_real.sh` contains the same clean-data sequence for bash. All commands run on CPU; video feature extraction is the slowest step and takes hours.

**1. Check the data.** Prints partition and class counts and reports missing media, to be compared with the official MELD counts.

```powershell
python -m src.run inspect --config configs/experiment.yaml
```

**2. Extract clean features** for the three splits (text, audio and video are cached once):

```powershell
foreach ($split in "train","dev","test") {
  python -m src.features.extract --config configs/experiment.yaml --split $split --modality all
  python -m src.features.extract assemble --config configs/experiment.yaml --split $split
}
```

**3. Extract corrupted features.** Corruption is applied to the raw signal before encoding, so each condition needs its own pass. Audio noise at 20, 10 and 0 dB signal-to-noise ratio, and text token dropout of 10% and 30%:

```powershell
foreach ($split in "train","dev","test") {
  foreach ($snr in 20,10,0) {
    python -m src.features.extract --config configs/experiment.yaml --split $split --modality audio --condition audio_snr$snr --corrupt audio:snr=$snr
    python -m src.features.extract assemble --config configs/experiment.yaml --split $split --condition audio_snr$snr
  }
  foreach ($d in 10,30) {
    python -m src.features.extract --config configs/experiment.yaml --split $split --modality text --condition text_drop$d --corrupt text:drop=0.$d
    python -m src.features.extract assemble --config configs/experiment.yaml --split $split --condition text_drop$d
  }
}
```

Optionally check an assembled condition:

```powershell
python -m src.features.check --config configs/experiment.yaml --split test --condition audio_snr20
```

**4. Development runs** (dev partition only; the test set is not touched):

```powershell
python -m src.run run --config configs/experiment.yaml --mode dev
python -m src.run resplits --config configs/experiment.yaml --k 20    # optional: variability across calibration draws
```

**5. Freeze the analysis plan and evaluate the test set once.** The reported results use `configs/experiment_amend.yaml`, which contains the ten corruption entries and writes to `outputs_amendment/`. Freezing writes a hashed lock file, and the run refuses to start if the plan has changed since:

```powershell
python -m src.run freeze --config configs/experiment_amend.yaml
python -m src.run run --config configs/experiment_amend.yaml --mode final
```

Freezing again resets the run-once guard, so run `freeze` only once per plan.

**6. Build tables and figures:**

```powershell
python -m src.report.make_tables  --dir outputs_amendment --out report_out
python -m src.report.make_figures --dir outputs_amendment --out report_out
```

**Reproducing without MELD or feature extraction.** The summary files of the reported run are in `outputs_amendment/`, so step 6 can be run directly on them. The test suite (`python -m pytest -q`) runs on synthetic data and does not need MELD.

## Experimental settings

| Setting | Value |
| --- | --- |
| Features | Text 768 (RoBERTa-base, mean-pooled), audio 88 (eGeMAPSv02), video 512 (ResNet-18, 8 frames), mask 3; 1,371 inputs |
| Classifier | MLP 1,371 → 256 → 128, ReLU, dropout 0.30; emotion and sentiment heads; modality dropout |
| Training | Early stopping on validation NLL (patience 8, at most 60 epochs); seeds 42 to 46; CPU |
| Conformal | Score 1 − p(y\|x); α = 0.10 (primary), 0.05, 0.20; n_min ∈ {30, 50, 100} |
| Corruption | Audio noise at 20, 10 and 0 dB SNR; text token dropout of 10% and 30%; matched and mismatched calibration |
| Uncertainty | 500 dialogue-level bootstrap resamples; ECE with 15 bins |

## Main findings

- Per-pattern thresholds kept emotion coverage within 0.016 of the 90% target in all seven patterns, against deviations of up to 0.082 (complete-input threshold) and 0.057 (pooled threshold), at about the pooled mean set size.
- Text corruption lowered coverage unless calibration matched it; audio noise did not.
- Fusion did not improve on text alone (emotion macro-F1 0.372 against 0.401).
- Coverage within classes was poor for every method (disgust 0.385, fear 0.328), so pattern-level conditioning does not give class-level reliability.

## Limitations

Missingness is simulated and independent of content. Utterances within a dialogue are dependent, so the finite-sample guarantee is not claimed and coverage is reported as an empirical quantity. One dataset, one nonconformity score and one set of corruption levels were studied. Video corruption was not evaluated. MELD is scripted sitcom dialogue, and its labels are annotator judgements, not measurements of inner states.
